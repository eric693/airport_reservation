搶單管理
發布搶單任務後，所有司機的 LINE 會同時收到推播通知
搶單流程說明
① 至「訂單管理」開啟任意訂單 → 右側「搶單模組」點「發布搶單」
② 所有啟用且設有 LINE User ID 的司機同時收到推播
③ 第一個按「 我要接單」的司機獲得訂單，其他司機無法再搶
④ 搶到後系統自動將完整客戶資料傳給司機，並可選擇自動通知客人司機資訊
️ 設定司機 LINE User ID
讓司機在 LINE Bot 中傳送「我的ID」，Bot 會回覆該司機的 LINE User ID
複製後填入「司機管理」頁面的「LINE User ID」欄位即可
